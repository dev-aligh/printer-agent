# نسخهٔ 1.11.0

بیلد پورتابل ۳۲ بیتی جایگزین فایل نسخهٔ 1.10.0 است.

- شامل اصلاح تراز صورت‌وضعیت افقی از سمت چپ است.
- محاسبهٔ طول محتوای اسناد حرارتی و تأیید تنظیمات ذخیره‌شدهٔ چاپگر حفظ شده‌اند.

نتیجهٔ چاپ فیزیکی به چاپگر و درایور وابسته است. پیش از اجرای فایل جدید، از منوی Agent کنار ساعت ویندوز «خروج» را بزنید.
