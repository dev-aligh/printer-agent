# نسخهٔ 1.8.0

بیلد پورتابل ۳۲ بیتی با اصلاحات موجود در تنظیمات کاغذ و درایور، جایگزین فایل نسخهٔ 0.1.7 است.

- گزینه‌های نوع سند قابل تغییر هستند.
- تنظیمات A5 و رول جداگانه به درایور ارسال می‌شوند.
- اگر فرم انتخاب‌شده ابعاد نادرست برگرداند، درخواست با ابعاد صریح دوباره بررسی می‌شود.
- انتظار بی‌پایان در مسیر چاپ محدود شده است.

برای صورت‌وضعیت، هنگامی که جهت چاپگر در ویندوز افقی باشد، قالب عمودی A5 به‌صورت کامل ۹۰ درجه چرخانده می‌شود. برای استفاده، کاغذ A5 و جهت افقی را ذخیره کنید. اجرای خودکار با ورود به ویندوز و کوتاه‌کردن خودکار رول بر اساس ارتفاع محتوا در این نسخه پیاده‌سازی نشده‌اند. چاپ فیزیکی روی دستگاه کاربر باید بررسی شود.

برای تعویض نسخه از منوی Agent کنار ساعت ویندوز «خروج» را بزنید و سپس فایل جدید را اجرا کنید.
