# نصب و Pairing

1. `Mirocab Print Agent Setup.exe` را با کاربر همان اپراتور پنل نصب و اجرا کنید.
2. Agent برای پنل‌های معتبر production و staging میروکب به‌صورت خودکار مجوز اتصال محلی دارد؛ Pairing token را کپی کنید.
3. توکن را در تنظیمات محافظت‌شدهٔ شرکت/سیستم پنل ذخیره کنید؛ آن را در `localStorage` یا داخل HTML چاپ قرار ندهید.
4. از فهرست پرینترهای ویندوز، با «تست چاپ» سلامت Spooler را بررسی کنید. انتخاب پرینتر و گزینهٔ سند باید در پنل برای همان سیستم/کاربر ذخیره شود.

## ملاحظات امنیتی

- listener فقط `127.0.0.1` است و دسترسی LAN ندارد.
- هر درخواست نیازمند `X-Mirocab-Pairing-Token` است.
- CORS فقط Originهای معتبر پنل میروکب را بازتاب می‌دهد؛ Origin ناشناس `403` می‌گیرد.
- مسیر پنل می‌تواند از HTTPS به localhost درخواست بفرستد؛ اتصال شبکه‌ای به Agent ایجاد نمی‌شود و preflight مربوط به Private Network Access نیز فقط برای همان Originهای معتبر پذیرفته می‌شود.
- payload حداکثر 8MB است. HTML را از پاسخ معتبر پنل بسازید و دادهٔ کاربر را escape کنید.

## محدودیت آزمون فعلی

این مخزن روی macOS آماده شده است؛ تولید و نصب نهایی exe و تأیید واقعی Windows 7 SP1 / Windows 10 و نمونه‌ای از پرینترهای مورد استفاده باید روی دستگاه‌های ویندوز اجرا شود. ماتریس آزمون در `docs/TEST-MATRIX.fa.md` قرار دارد.
