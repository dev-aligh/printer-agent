# نسخه 0.1.6 — پورتابل ۳۲ بیتی

- دکمه ذخیره، اندازه کاغذ و جهت چاپ را در Printing Preferences ویندوز برای همان پرینتر و همان کاربر اعمال می‌کند. پرینتر پیش‌فرض سیستم و تنظیمات سایر پرینترها تغییر نمی‌کند.
- تنظیمات پیش‌فرض، تنظیم پایهٔ درایور/مدیر همان صف چاپ را بازیابی می‌کند؛ این عملیات ریست کارخانه‌ای سخت‌افزار نیست.
- اگر چند نوع سند یک پرینتر داشته باشند، آخرین ذخیره تنظیم کاغذ و جهت مشترک آن پرینتر است. چاپ تنظیم فعلی ویندوز را می‌خواند و تنظیم قدیمی سند را روی پرینتر بازنویسی نمی‌کند.
- تعداد نسخه، حاشیه‌ها و Scale در سطح چاپ ایجنت باقی می‌مانند؛ Cut برای داده RAW/ESC-POS است. این موارد تنظیم عمومی مشترک همه درایورهای ویندوز نیستند.
- اگر درایور کاغذ یا جهت درخواست‌شده را نپذیرد، ذخیره موفق اعلام نمی‌شود. پشتیبانی از طول/عرض سفارشی رول به درایور وابسته است.
- تنظیمات نسخه قبلی هنگام اجرای برنامه خودکار روی پرینترها اعمال نمی‌شوند. برای هر پرینتر موردنظر یک‌بار ذخیره را بزنید.

فقط خروجی portable ia32 ارائه شده است. helper دات‌نت AnyCPU روی ویندوز ۳۲ بیتی به صورت ۳۲ بیتی و روی ویندوز ۶۴ بیتی با معماری بومی اجرا می‌شود.

اعتبارسنجی: تست‌های Node و تست واقعی ذخیره A5 افقی، بازگردانی پیش‌فرض و تغییر نکردن سایر صف‌ها روی Microsoft Print to PDF. چاپ فیزیکی روی پرینتر حرارتی و Windows 7 نیاز به تست دستگاه دارد.

مبنای پیاده‌سازی: [تنظیمات هر کاربر در Windows](https://learn.microsoft.com/en-us/windows/win32/printdocs/printer-info-9) و [اعتبارسنجی تنظیمات توسط درایور](https://learn.microsoft.com/en-us/windows/win32/printdocs/documentproperties).
